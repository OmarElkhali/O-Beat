# O-Beat downloads

Download the latest signed APK from [GitHub Releases](https://github.com/OmarElkhali/O-Beat/releases/latest).

Choose the universal APK for your installed variant (`full` or `core`).
It includes ARM 64-bit, ARM 32-bit, x86 and x86_64 libraries. Android 7.0 or
later is required. Install it over the existing production application to
keep your data; the original application ID and signing key must match.

APK binaries are release assets rather than source files in this directory.
See [the release guide](../docs/RELEASING.md) for signing and publication.
